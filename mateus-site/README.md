# Mateus Oliver — Growth Marketing

Reconstrução em Next.js + React + CSS baseada no site público fornecido.

## Rodar

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Imagens

As imagens foram mantidas apontando para os mesmos arquivos públicos do site original em `mateus-oliver-growth.arcane-moon-3293.chatgpt.site`.

Se for publicar fora desse domínio, baixe/copie as imagens para `public/images` e troque as URLs no `app/page.tsx`.

## Framer

O código usa React e CSS padrão. Para Framer, a estrutura visual pode ser convertida para um Code Component; o CSS contém as regras responsivas e as seções já separadas semanticamente.
